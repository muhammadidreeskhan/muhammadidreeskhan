## ⚡ What I'm Actually Hired For

Most developers can build you a nice-looking Next.js site. Fewer can move a
site that already ranks — a WordPress catalogue, a legacy B2B store, an
established service site — onto a modern stack **without watching organic
traffic fall off a cliff on launch day**.

That's the work I do: crawlability, redirect maps, canonical hygiene,
rendering strategy, and Core Web Vitals treated as build requirements
rather than a post-launch cleanup ticket.
